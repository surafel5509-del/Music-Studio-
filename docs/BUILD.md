# Building WaveStudio from Source

## Quick Start (Android Studio)
1. Install Android Studio Hedgehog (2023.1.1) or newer.
2. Open the project root directory (`WaveStudio/`).
3. Accept the SDK license and let Gradle download dependencies (first sync).
4. Connect an Android 8.0+ device or start an emulator.
5. Click **Run** ▶️.

## Command-line Build
```bash
# Debug APK
./gradlew assembleDebug

# Release APK (requires a release keystore)
./gradlew assembleRelease
```

The Gradle wrapper (`./gradlew`) will be generated by Android Studio when you first open
the project. If it is missing, regenerate it with:
```bash
gradle wrapper --gradle-version 8.4
```
(requires a local Gradle installation).

## Generating a Release Keystore
```bash
keytool -genkeypair -v \
  -keystore app/release.keystore \
  -alias wavestudio \
  -keyalg RSA -keysize 2048 -validity 10000
```

You can also set keystore passwords via Gradle properties (recommended, do NOT commit your keystore):
```properties
# ~/.gradle/gradle.properties
WS_STORE_PASS=your-store-password
WS_KEY_PASS=your-key-password
```

## SDK/NDK Requirements
- `compileSdk = 34`
- `minSdk = 26` (Android 8.0)
- `targetSdk = 34`
- Android NDK 25.2.9519653 (installed via SDK Manager → NDK (Side by side))
- CMake 3.22.1+ (SDK Manager → CMake)

## Offline Builds
The project is designed to build without internet access once the Gradle cache is populated.
After a successful online build, you can use Gradle's `--offline` flag:
```bash
./gradlew assembleDebug --offline
```

## APK Output
- Debug: `app/build/outputs/apk/debug/app-debug.apk`
- Release: `app/build/outputs/apk/release/app-release.apk`

## Running Tests
```bash
./gradlew testDebugUnitTest          # Unit tests (JVM)
./gradlew connectedDebugAndroidTest  # Instrumented tests (device)
```
